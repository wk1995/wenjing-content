# 抖音脚本输出规则

Use this reference when generating the final script and storyboard.

## 种草视频

Default duration: 30 seconds.

Prioritize:

- Friend-like tone.
- Scene-based pain or desire.
- 1 to 3 selling points.
- Sensory detail and personal experience.
- Soft but clear CTA.

Output:

```text
## 爆款公式摘要

## 完整脚本
[0-3s] ...
[3-8s] ...
[8-18s] ...
[18-27s] ...
[27-30s] ...

## 分镜表
| 镜号 | 时长 | 景别 | 画面内容 | 旁白/字幕 | 拍摄建议 |

## 审校修改清单

## 合规风险提示
```

## 千川投放素材

Default duration: 15 seconds.

Prioritize:

- Strong first 3 seconds.
- Dense information.
- Direct selling points.
- Proof before promise.
- Harder CTA: click, enter livestream, claim offer, order.

Avoid question-only openings. Prefer data, pain, contrast, or benefit.

## Oral Delivery Rules

- Keep most spoken lines under 15 Chinese characters.
- Read the script aloud mentally; rewrite any sentence that feels stiff.
- Replace written phrases with spoken phrases:
  - "进行操作" -> "点一下"
  - "接下来我们将" -> "我们来"
  - "综上所述" -> direct ending
  - "显著提升" -> concrete felt result
