# 抖音竞品分析框架

Use this reference when the user provides Douyin or short-video competitor links, downloaded videos, transcripts, screenshots, or manual notes.

## 7-Dimension Breakdown

1. 钩子分析
   - 前 3 秒文案钩子：痛点、反常识、数据、场景、悬念、利益。
   - 前 3 秒视觉钩子：产品堆叠、动作冲击、画面突变、文字弹出、POV、视觉奇观。
   - 文案和画面是否共同强化同一个信息。

2. 分镜结构
   - 用时间轴拆解镜头。
   - 记录景别、画面、旁白、字幕、转场。

3. 节奏设计
   - 快切点、停顿点、信息密度、BGM 和音效变化。

4. 视觉元素
   - 色调、滤镜、字幕样式、产品展示方式、构图特点。

5. 转化设计
   - CTA 出现时机、价格锚定、紧迫感、评论区或直播间引导。

6. 合规风险
   - 绝对化用语、功效承诺、虚假对比、诱导表达、医疗或金融高风险表述。

7. 可复制要素
   - 可复制：钩子句式、镜头顺序、节奏、CTA、证明路径。
   - 不可复制：达人身份、特殊场景、品牌势能、独家素材。
