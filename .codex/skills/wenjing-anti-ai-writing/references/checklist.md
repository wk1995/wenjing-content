# 去 AI 味检查表

## 优先修复

| 信号 | 处理方式 |
| --- | --- |
| 空泛的“这很重要 / 正在改变一切” | 写清对谁、在哪个场景、有什么具体变化；没有信息就删。 |
| “不仅……更……”或“不是……而是……”反复出现 | 保留真正构成对比的句子，其余直接陈述。 |
| “首先、其次、最后”把自然叙述切成清单 | 只有顺序本身重要时才保留；否则用因果、转折或场景衔接。 |
| “专家、业内人士、很多人认为” | 换成可核验的主体和来源；无来源则删。 |
| 一串形容词、抽象名词或口号 | 落到对象、动作、限制或例子。 |
| 每段句长、语气、结构相同 | 合并重复段，穿插短句、具体画面或必要的停顿。 |
| 无依据的第一人称体验 | 删除，或明确为作者提供的真实体验与条件。 |

## 保留什么

- 作者已提供的口头禅、判断、犹豫和偏好。
- 技术文章里必要的术语、条件、数据、来源和限定语。
- 读者确实需要的列表、表格和步骤。
- 有用但不完美的自然表达；不要把所有句子抛光成同一腔调。

## 终稿自检

- 每一段是否带来新信息，或推进了论证？
- 读者能否说出文章解决了什么具体问题？
- 事实、适用条件和不确定性是否仍然准确？
- 能否删掉一句总结而不损失信息？若能，删掉。
- 结尾是否给出和正文相关的下一步，而非机械求赞或泛泛互动？
