# Tardiformatter WeChat Format

Use this skill to prepare Wenjing Markdown drafts for `tardiai/tardiformatter`, a browser-based Markdown formatter for WeChat public account articles.

Source repository: https://github.com/tardiai/tardiformatter

## Core Workflow

1. Locate the article draft, usually `projects/{project-slug}/wechat/article.md`.
2. Clean the Markdown before formatting:
   - Keep one clear title at the top.
   - Use short mobile-friendly paragraphs.
   - Keep lists simple and flat when possible.
   - Use fenced code blocks with a language tag for technical articles.
   - Keep tables small; large tables are hard to read in WeChat.
   - Use standard Markdown image syntax for committed drafts.
3. Choose a tardiformatter style based on article intent.
4. Open tardiformatter online or run it locally, paste or upload the Markdown, inspect the preview, then use its copy button to transfer rich text into the WeChat editor.
5. Validate in the WeChat editor, because the final compatibility check happens after paste.

Read `references/tardiformatter-operation.md` when you need implementation details, local run commands, style keys, image behavior, or troubleshooting.

## Style Selection

- Use `wechat-tech` for developer tutorials, code-heavy explainers, and engineering notes.
- Use `wechat-anthropic` for polished technical essays or AI product analysis.
- Use `wechat-ft`, `wechat-nyt`, `guardian`, `nikkei`, or `lemonde` for news, business, policy, media, or global-perspective articles.
- Use `wechat-deepread` or `wechat-medium` for longform opinion and reflective essays.
- Use `wechat-default` or `wechat-elegant` when reliability and conservative formatting matter more than visual character.
- Use art/design styles such as `kenya-emptiness`, `hische-editorial`, `ando-concrete`, or `gaudi-organic` only when the article concept calls for a strong editorial look.

## Markdown Preparation Rules

- Do not commit `img://...` links to the repository unless the user explicitly wants a browser-session-only draft. These links are generated by tardiformatter and depend on that browser's IndexedDB.
- For image grids, place consecutive image Markdown lines together. Tardiformatter groups consecutive images into grid-style layouts and converts them during copy for WeChat compatibility.
- If images are local files, tell the user to paste or drag them into the browser formatter during final layout; keep repository drafts on stable local paths or source URLs.
- Avoid raw HTML unless necessary. Tardiformatter is optimized for Markdown input plus its own inline-style conversion.
- For rich text copied from Feishu, Notion, Word, or web pages, use tardiformatter's paste conversion, then inspect the Markdown before copying to WeChat.

## Verification

Before considering the work done:

1. Confirm the Markdown preview renders headings, lists, quotes, code, tables, and images as intended.
2. Check that the selected style matches the article's tone and platform goal.
3. If the article has images, verify every image appears in preview and after paste into WeChat.
4. If the article has code blocks or tables, paste into WeChat and inspect them manually.
5. Note any remaining manual step clearly, such as final paste into the WeChat editor or image replacement from the media library.
