# 公众号文章写作流程

4 步完成高质量公众号文章：搜索资料 → 撰写文章 → 生成标题 → 排版优化

## Step 1: 搜索资料

先检查用户是否给了项目文件、`sources.md`、已有草稿或资料链接。若资料已经在项目内，优先基于项目资料写作；若主题涉及“最新”“最近”“趋势”“价格”“政策”“产品能力”等会变化的信息，再使用 WebSearch 核验一手来源。

```
搜索要求：
1. 并行搜索多个来源（官方文档、X/Twitter、Reddit、技术论坛）
2. 优先获取最新资料（当月/当季）
3. 可启动多个并行 Task 加速搜索
4. 深度总结搜索结果
```

## Step 2: 撰写文章

有 `CLAUDE.md` 时可读取它补充写作风格；没有时不要阻塞，直接使用仓库 `AGENTS.md`、项目 `brief.md`/`plan.md`/`sources.md` 和现有模板风格。

撰写要求：
- 普通文章 1000-1500 字；技术科普长文可放宽到 2500-3500 字
- 故事化开头，带情感色彩（兴奋/焦虑/好奇）
- 准备 2-3 个备选标题
- 结构：效果展示 → 问题描述 → 步骤教学 → 升华总结
- 遵循 AGENTS.md、项目文件、现有模板或用户额外指定的写作风格和结尾语
- 面向微信公众号发布时，正文段落要短，避免教材式连续编号；每个概念接一个例子
- 平台输出文件只保留文章正文和必要资料来源，不把标题池、写作备注和内部资料编号混进发布稿

## Step 3: 生成标题

生成 5 个爆款标题，特点：
- **痛点明确**：直击读者痛处（"还在手动..."）
- **数字吸引**：具体数字更有说服力（"3分钟"、"5个技巧"）
- **结果导向**：承诺具体收益（"效率暴涨10倍"）
- **情绪调动**：惊、神技、秘籍等词汇
- **悬念设置**：引发好奇心

## Step 4: 排版优化

优化建议：
1. **段落结构**：每段 3-5 行，重要数据单独成段加粗
2. **配图位置**：标题下方封面图、步骤后效果图、结尾总结图
3. **代码块**：前后留白，语法高亮
4. **金句**：单独成段，增强记忆点

## 发布交付

- 仓库稿：保留 front matter，`status` 可按进度设为 `draft`、`review`、`ready` 或 `published`。
- 粘贴稿：去掉 front matter，只保留标题、正文和面向读者可见的资料来源。
- 引用处理：`sources.md` 中保留完整来源表；发布稿中不要残留 `[S1]` 这类内部标记，改成自然表述或文末“资料来源”。
- 直接粘贴到微信公众号编辑器时，只放入纯 Unicode Markdown；不要自行构造 HTML 富文本剪贴板。需要富文本样式时，交给 Markdown 公众号排版器或微信公众号编辑器的 Markdown 转换功能。
- 若粘贴后出现乱码、HTML 源码或 `<section ...>`，立即清空并重置为纯文本粘贴稿。

## 示例

用户请求：
```
帮我写一篇关于 Claude Code 使用技巧的公众号文章
```

执行流程：
1. 搜索 Claude Code 最新功能和使用技巧
2. 读取项目资料和可用的风格文件
3. 撰写 1200 字左右的教程文章
4. 生成 5 个爆款标题供选择
5. 提供排版和配图建议
