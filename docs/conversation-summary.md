# 写作类 Skill 对话整理

来源：Codex 对话「查找写作类skill」中关于写作 Skill 的部分。

## 最终落地的三个通用 Skill

对话中先检索了微信公众号文章、视频脚本和小红书文案三类需求，最后选择并安装了三个最通用的 Skill：

| Skill | 对应内容 | 安装来源 | 定位 |
| --- | --- | --- | --- |
| `wechat-article-writer` | 微信公众号文章 | `iamzhihuix/happy-claude-skills` | 从资料搜索到文章排版的一体化流程 |
| `huashu-douyin-script` | 抖音短视频脚本 | `alchaincyf/huashu-skills` | 竞品拆解、爆款公式、脚本和分镜 |
| `copywriting-skills` | 小红书正文文案 | `vivy-yi/xiaohongshu-skills` | 小红书正文、品牌语气、产品推荐 |

## 当时提到但未作为通用必装的候选

这些 Skill 在对话中作为补充项出现，适合后续按需安装：

| Skill | 适合场景 |
| --- | --- |
| `wechat-article-formatter` | 已有公众号正文，只需要排版和发布适配 |
| `huashu-video-outline` | 只需要短视频大纲，不需要完整脚本 |
| `huashu-script-polish` | 已有脚本，需要更口语、更短视频化 |
| `title-writing` | 小红书标题专项优化 |
| `seeding-copywriting` | 小红书种草文案专项 |
| `script-writing` | 小红书视频脚本专项 |

## 项目命名结论

对话中最终确定：

- 中文项目名：文镜
- GitHub 仓库名：`wenjing-content`
- 项目简介：面向微信公众号、小红书和抖音的多平台内容创作工具

## 整理原则

本仓库只沉淀写作类 Skill 的使用方式和项目协作规范，不收录与 GitHub、宠物、设计、表格等无关 Skill。
