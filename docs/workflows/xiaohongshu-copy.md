# 小红书正文文案工作流

对应 Skill：`copywriting-skills`

## 适用场景

- 小红书正文文案
- 产品种草笔记
- 教程笔记
- 测评笔记
- 个人经历和情绪故事
- 品牌语气改写

## 输入信息

| 字段 | 说明 |
| --- | --- |
| 主题 | 笔记要表达的核心内容 |
| 内容类型 | 教程、测评、种草、清单、故事、避坑 |
| 人设 | 学生党、职场人、宝妈、店主、专业顾问等 |
| 产品或素材 | 卖点、价格、场景、对比、使用体验 |
| 目标人群 | 想吸引谁 |
| 语气 | 真实、兴奋、温柔、专业、犀利、姐妹感 |
| CTA | 收藏、评论、关注、私信、进店等 |

## 标准流程

1. 钩子开头：一句话点出痛点、惊喜、反差或承诺。
2. 场景铺垫：说明为什么这个内容和读者有关。
3. 价值交付：给 3 到 5 个清晰要点。
4. 真实细节：加入价格、时间、场景、体验或踩坑。
5. 情绪连接：用第一人称表达感受。
6. 明确 CTA：告诉读者下一步做什么。

## 推荐结构

```text
开头钩子

为什么想写这篇

核心内容 1
核心内容 2
核心内容 3

个人体验或避坑提醒

结尾 CTA
```

## 注意事项

- 不要只写“很好用”“很推荐”，要给具体细节。
- 不要写成广告说明书，要像真实用户分享。
- 正文可以口语，但信息要清楚。
- 教程和清单类内容要方便扫读。
- 标题专项优化后续可接入 `title-writing`。

## 产出格式

```text
## 正文

## CTA

## 可选标签

## 可继续优化的标题方向
```
