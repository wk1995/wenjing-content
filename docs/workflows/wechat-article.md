# 微信公众号文章工作流

对应 Skill：`wechat-article-writer`

## 适用场景

- 写公众号长文
- 写教程型文章
- 写自媒体观点文章
- 写带资料搜索的深度内容
- 为已有主题生成爆款标题和排版建议

## 输入信息

| 字段 | 说明 |
| --- | --- |
| 主题 | 文章要讲什么 |
| 目标读者 | 写给谁看 |
| 目标 | 科普、转化、种草、品牌表达或观点输出 |
| 资料要求 | 是否需要搜索最新资料 |
| 风格 | 专业、故事化、口语化、犀利、温和等 |
| 字数 | 默认 1000 到 1500 字 |
| 结尾 | 是否需要关注、留言、私信或购买引导 |

## 标准流程

1. 资料搜索：围绕主题找最新、可信的资料。
2. 结构设计：确定开头、问题、解决方案、案例和结尾。
3. 正文撰写：使用故事化开头，控制段落长度。
4. 标题生成：至少给 5 个备选标题。
5. 排版建议：给段落、加粗、配图和金句位置。

## 推荐文章结构

```text
标题

开头：用故事、冲突、问题或结果抓住读者

第一部分：读者正在遇到什么问题

第二部分：为什么这个问题值得重视

第三部分：具体方法、步骤或案例

第四部分：总结和观点升华

结尾：行动引导
```

## 产出格式

```text
# 推荐标题

## 备选标题

## 正文

## 排版建议

## 配图建议
```
