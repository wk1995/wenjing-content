# 模板说明

这里存放可复用模板，不存放具体项目内容。

## 分类

- `project/`：项目级模板，用于创建 `projects/{project-slug}/` 下的项目简介、原始 brief、资料来源、选题调研、内容方案和跨平台共用素材。
- `platforms/`：平台级模板，用于创建项目下各平台文件夹中的具体内容。

## 使用原则

- 具体项目的方案、选题调研、资料来源都归属于项目目录，不放在模板目录。
- 更新模板时，在 `templates/CHANGELOG.md` 记录日期、影响范围和迁移建议。
- 项目内容文件应在开头记录使用的模板名称和版本，方便后续追踪。
