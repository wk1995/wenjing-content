# 模板更新记录

## 2026-10-15

- 平台模板增加 `content_type`。可选值为 `video`（视频）、`article`（文章），多个标签用逗号分隔。
- 抖音、微信视频号标为视频；小红书同时标文章和视频；公众号、掘金、CSDN、博客园、思否、InfoQ、开源中国标为文章。
- 增加平台模板：微信视频号、CSDN、博客园、思否、InfoQ、开源中国。
- 项目模板中的平台列表示例同步增加这 6 个平台；已有项目不强制补齐目录。
- 接口核验写入 `docs/platform-apis.md`。只有博客园 MetaWeblog 能作为官方随笔发布接口；其余平台本次没有核到公开的内容发布 API 或官方 MCP。
- 模板只记录成稿字段和发布边界，不包含自动发布脚本。
- 博客园发布脚本放在 `.codex/skills/cnblogs-publisher`，不属于模板。默认存草稿。
