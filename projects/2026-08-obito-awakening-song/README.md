一支约 3 分 20 秒的竖屏同人叙事视频脚本。前半段以明亮、兴兴向荣的成长幻境讲述带土的“本可以拥有”的人生；幻境裂开后，镜头回到忍界大战战场，落点是他从毁灭走向选择守护的转折。

## 文件说明

- `brief.md`：原始创作需求与边界
- `plan.md`：叙事、节奏与制作策略
- `sources.md`：用户提供设定、授权边界与素材清单
- `shared/`：跨版本可复用的主线与关键表达
- `douyin/script.md`：可配乐剪辑的完整脚本
- `douyin/storyboard.md`：逐镜执行分镜
