# 共享大纲（跨平台）

## 大纲

1. 开场建立反差：她是“水神”时的高台与众人瞩目，转场到空场景中的孤独
2. 伪装压力上升：民众、审判、镜头切分反复体现“身份崩解”
3. 崩塌与停顿：雨、水面、镜子碎裂，副歌前后完成情绪下沉和爆发
4. 独白与释放：黑屏独白“我扮演了五百年的水神……已经足够了。”
5. 收束：回到真实表演态度，“这一次，我只做芙宁娜。”

## 口径建议

- 故事语气：抑制夸张，保留克制
- 情绪主轴：压抑 → 崩溃 → 觉醒
- 核心象征：镜子、水滴、海浪

## 平台复用方式

- 视频版：直接复用 `video/` 全量版本文件
- 文案版：转写为短文时保留 4→5 步核心逻辑与句式
