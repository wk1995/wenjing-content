# 共用观点与表达口径

## 当前一句话观点

> 鸡蛋的营养价值，要连着份量、蛋白与蛋黄的分布，以及整天饮食一起看。

## 营养事实索引

具体数值和限定词以 [资料库](../sources.md) 为准，避免在多份文件中维护不同版本。

| 表达任务 | 事实卡 | 来源 | 保留的口径 |
| --- | --- | --- | --- |
| 说明一份蛋白质的量级 | F16 | [S12] | 50克去壳熟全蛋参考条目；不当作每颗蛋固定值 |
| 说明蛋黄也有蛋白质 | F17 | [S12] | 分部对比采用同为生的条目，不计算生熟损失 |
| 说明两部分营养分布 | F18、F20 | [S12] | “含有”和“较集中”不推成无条件多吃 |
| 解释胆碱 | F19 | [S13] | 生理功能不等于吃蛋提高智力 |
| 解释一般指南 | F12 | [S2][S14] | 2022版，周推荐量，不统一换算个数 |

## 可复用表达

- 开篇：“早餐留不留蛋黄，先看看两部分各提供什么。”
- 读数：“这份数据，先要看清它按多少克来算。”
- 部位解释：“蛋白是一个部位的名字，蛋白质是一类营养素。”
- 结尾：“把一种食物放回整天的饮食里，再看它的作用。”

## 避免的表述

| 容易失真的说法 | 改写方向 |
| --- | --- |
| 50克的鸡蛋有50克蛋白质 | 明确可食份量与营养素含量的区别 |
| 蛋黄没有蛋白质，或者只剩脂肪 | 解释不同营养素在两个部分的分布 |
| 鸡蛋90%的营养都在蛋黄 | 不把不同单位的营养素加成一个“营养总量” |
| 鸡蛋含胆碱，所以越吃越聪明 | 只说必要生理功能，不承诺认知改善 |
| 现场称出了6克蛋白质 | 电子秤只能称总重量；成分量是参考数据 |
| 美国数据库说明中国每颗蛋都是这个数 | 标明版本、食物条目和份量，不泛化总体 |
| 所有人每天必须吃一个 | 引用指南范围，保留个人饮食安排 |

## 后续主题保留边界

壳色不直接判断总体营养；系带不用于不明异物鉴定；凝固不代替杀菌；外观与气味不排除致病菌。证据仍按资料库S1、S3–S10保留，后续制作前复核相应事实卡。
