## 基本信息

- 产品名称：WorkBuddy 排查实录
- 产品品类：技术科普
- 核心卖点：复制 API Key 被换成另一串，不是编辑器手滑
- 目标人群：会复制 API Key 的开发者，以及用电脑办公的普通人
- 价格或活动：无
- 品牌调性：口语、短句、不吓唬，但把边界说清楚

## 视频目标

- 脚本类型：技术科普
- 目标时长：90 秒
- 投放目标：不投放
- CTA：想看完整排查，去看长文
- 发布或投放平台：抖音
- 核心目标：完播 / 让人停下来检查自己的复制结果

## 竞品素材

- 无对标视频。结构来自公众号同一事实。

## 拍摄限制

- 可用画面素材：自制字幕卡、打码后的剪贴板历史示意、任务时间戳示意。不要录到完整密钥、桌面用户目录和未打码的 Win+V。
- 可出镜人物：可不露脸，口播即可。
- 不能使用的素材：对话原文截图（含完整 key）、样本文件、安装包下载页。

## 口播稿

【0–3 秒】
你复制的 API Key，粘贴出来可能已经不是它了。

【3–15 秒】
我复制一条 hlg 开头的密钥，历史记录里却多出一条。头和尾没变，中间换了，长度还少了一位。两次只隔一秒。不是我连按了两下。

【15–35 秒】
后来对着时间看：我按下复制之后大概两百毫秒，另一个程序又写了一条。我的那条带着编辑器格式，它那条只有纯文本，还没有窗口主人。
普通句子它不动。没见过的、同样形状的密钥，它照样换成新的。

【35–55 秒】
我把 WorkBuddy、飞书、编辑器都关了，还在换。远程工具也退出了，还在换。最后把一大堆软件全部暂停，它还在写。只有按住一个系统进程，改写才停。
那个 exe 文件是微软签名的，是真的。坏的是进程里面被塞进去的代码。

【55–75 秒】
谁把它拉起来的？半年前一份从跳转网站下的安装包。它注册了两条看起来像系统任务的计划任务，开机就去跑一个放在用户目录里的小程序。小程序再把代码注进那个系统进程。所以你在任务管理器里看不到一个名叫木马的进程。

【75–90 秒】
先断网。到另一台设备上把这串密钥作废。不要在这台电脑上生成新的。删任务只能止血，不能证明机器已经干净。完整过程我写在长文里了。

## 字幕要点

- 主字幕跟口播，一行不超过 16 个字。
- 屏幕大字只留三句：「复制之后又被写了一次」「签名是真的，代码不是」「新密钥不要在这台机器上生成」。

## 合规

- 不说「你的电脑一定中招了」。这是一台机器上的一次排查。
- 不展示完整密钥，不念安装包下载域名。
- 不给清理命令。结尾只给顺序：断网、换密钥、再处理开机项。
