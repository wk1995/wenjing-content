# SSH 学习共用主线

## 主线

先回答“已有远程工具，为什么还要学 SSH”，按任务解释学习价值，再从“我如何在自己的电脑上操作另一台电脑”出发，依次解决角色、地址、身份、权限和功能。每一步都能关联到一个实际动作。

## 内容顺序

1. 先按任务比较远程桌面、SSH、文件传输与远程开发，解释无桌面管理和自动化价值，再区分终端、Shell、协议与工具。
2. 先解释提示符、路径和基础操作，在家庭 Mac 建立自连接并确认会话；同一局域网 Windows 登录 Mac 作为选做。
3. 从主机身份和用户身份两个方向解释密钥与信任文件，完成 Mac 自连接授权，再选学 Windows 私钥留本机、授权公钥加到 Mac 的完整过程。
4. 公钥认证成功后，分清客户端配置与服务端配置，保存连接别名并完成文件往返，解释本机当前目录与远端主目录。
5. 区分回环、局域网和公网；用双网卡 B 解释监听、SSH 跳板与系统 IP 转发的区别，再解释公网前提及转发路径。
6. 管理授权、主机身份和配置变更，理解简化连接流程。
7. 将排错按阶段组织成可独立查阅的手册。

## 共用案例

学习密钥、ssh-lab 别名和往返文本文件均围绕家庭 Mac。案例身份与地址是虚构示例，不代表已发现或测试用户设备。

## 跨平台复用方式

当前用于个人学习。未来如果改编公众号或掘金，应从独立问题切入；若改为短视频，每条只解释一个困惑。具体平台单篇大纲仍需写入项目 sources.md。
