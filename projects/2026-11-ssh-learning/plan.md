# SSH 个人学习内容方案

## 核心判断

> 先在自己的设备上完成一次可解释的 SSH 登录，再学习身份认证、文件传输和跨网络连接，比直接堆参数更适合当前读者。

## 内容策略

- 主线：用途与角色 → Mac 自连接 → 家庭 Windows 连 Mac → 用户密钥 → 别名与文件 → 网络和隧道 → 安全与原理。
- 阅读组织：入门两篇、实用两篇、进阶三篇、独立排错一篇；README 提供路线和进度清单。
- 教学结构：先给场景，再解释概念与命令；实操标明执行位置、前提和预期；每篇附自测及答案。
- 证据来源：OpenSSH 官方手册、苹果与微软系统文档、Ubuntu 文档、IETF RFC；完整映射见 `sources.md`。
- 写作风格：直接面向用户，采用中文解释；不过早引入全套 Linux 管理知识。
- 示例约定：虚构账号 `alice`、虚构家庭 IP `192.168.1.50`；自连接用 `127.0.0.1`；独立学习密钥名避免与默认工作密钥冲突。

## 平台拆分方案

当前产物为项目 `doc/` 下的个人学习正文。平台改编在用户提出后再规划，不生成占位平台稿。

## 复用资产

- 共用主线：`shared/outline.md`。
- 关键表达：`shared/key-points.md`。
- 文字示意图：两端角色、登录流程、端口转发路径；均为本项目原创解释图，无外部媒体资产。
- 可复用案例：Mac 自连接、公钥认证、单文件往返传输。

## 风险与待确认

- macOS 与 Windows 菜单入口可能随版本变化；本机版本和企业管理策略未确认。
- 开启远程登录可能接收局域网连接；选择当前练习账号，结束后可关闭。
- 密钥生成不覆盖已有文件；公钥授权追加不覆盖原列表；传文件前注意目标同名覆盖。
- 自连接只能证明本机相应流程成立，不能当成跨设备或跨公网已验证。
- 隧道示例要求服务端另有 HTTP 服务且允许转发；不把监听成功当成目标服务可用。
- 不代用户修改设备、路由器、防火墙，不生成或提交真实密钥。
