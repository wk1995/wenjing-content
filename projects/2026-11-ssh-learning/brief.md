# SSH 学习文档需求

## 背景

用户先要求从默认分支建立编写 SSH 内容的分支，随后要求结合网络资料与通用知识教学，再明确先制作面向自己的文档，可按知识深度拆文件。

## 目标

- 让零基础读者理解 SSH，并用现有设备完成基础连接、认证和文件传输练习。
- 将入门、实用、进阶和排错内容拆开，支持逐篇学习。
- 保留一手来源和系统适用范围，后续依据真实反馈修订。

## 受众

- 核心读者：用户本人，新手小白。
- 用户提供的设备情况：公司使用 Mac；家里有 Mac 和 Windows。
- 用户提供的资源情况：目前没有远程电脑或云服务器可用于既有远程连接，先学基础。
- 尚未确认：系统具体版本、是否有管理员权限、家庭网络互访情况、OpenSSH 实际版本。
- 常见困惑：终端与 SSH 混淆、本地与远程混淆、私钥与公钥混淆、局域网地址当成公网地址。

## 内容边界

- 必须覆盖：概念、首次连接、主机身份、密码和公钥认证、连接配置、传文件、网络前提、隧道概念、安全习惯、排错。
- 实操主线：家庭 Mac 自连接，再扩展到同一家庭网络的 Windows 连接 Mac。
- 进阶主线：跨网络为什么不同、转发路径与简化协议原理。
- 暂不展开：云厂商购买流程、VPN 产品选型、路由器具体配置、Windows 服务端部署、企业证书体系、算法调优。
- 不能宣称：已在用户设备上完成实验、已确认公司允许改配置、已打通公司到家的网络。

## 平台范围

本阶段仅制作个人学习文档，正文在 `doc/`。微信公众号、小红书、抖音、掘金均未安排具体输出。

## 补充需求

- 用户追加了多网卡、不同网段的 A/B/C 场景，询问 B 的 SSH 怎样配置，并要求完善文档。
- 本次按“AB 一个网段、BC 另一个网段、B 双网卡”的教学拓扑组织；这是对描述的场景解释，实际设备系统、地址和网段尚未提供。
- 增补范围：B 的监听地址、A/C 分别登录 B、A 经 B 登录 C、与系统路由转发的区别，以及对应排错。主内容归第 05 篇，查阅步骤归第 08 篇。

## 学习动机补充需求

- 2026-11-04，用户询问已有远程工具时 SSH 的存在价值，并要求把解释放到学习文档开头，再提交推送。
- 交付位置：第 01 篇首节；README 链接到该节，保留原有八篇结构。
- 覆盖内容：按任务选择工具、无图形桌面设备、脚本自动化、VS Code Remote - SSH 例子、跳板与隧道价值、用户当前应掌握的范围。
- 表达边界：不把学习 SSH 写成所有远程操作的前置要求，不把 SSH 描述成自动穿透网络或替代所有远程工具。

## 交付物

- 静态链接、命令语法与示例客户端配置检查；不自动开启 SSH、生成真实密钥或连接用户设备。
