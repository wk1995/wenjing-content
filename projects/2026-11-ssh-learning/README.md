# 给你的 SSH 分层学习手册

这套文档面向刚接触 SSH 的你：公司使用 Mac，家里有 Mac 和 Windows，目前没有远程服务器。先用自己的设备学会连接，再逐步理解密钥、文件传输和网络。前四篇不需要购买云服务器。

## 从哪里开始

如果你正在疑惑“已经有远程桌面工具，为什么还要学 SSH”，先读[第 01 篇开头的用途比较](doc/01-foundations.md#有了远程工具-为什么还要学-ssh)，判断它能解决哪些实际任务，再开始命令练习。

按表中顺序阅读。第一次只读 01 和 02，完成一次登录与退出就可以停下来；不需要先把进阶篇读完。时间是学习安排的粗略估计，遇到环境问题可暂停并查 08。

你可以分三轮学：

1. **先用一台家庭 Mac 走通主线**：01 → 02 的路线 A → 03 的 Mac 自连接练习 → 04。02 的 Windows 路线可以暂时跳过，不影响继续学。
2. **有两台电脑时再做跨设备练习**：02 的路线 B → 03 的 Windows 公钥登录选学部分。Windows 发起连接，但登录成功后的命令会在目标 Mac 执行。
3. **有具体需求时读进阶篇**：05 中多网卡和跳板是示例拓扑，隧道可用一台 Mac 选做；06 学习日常习惯，07 随时回来看原理，08 用来查问题。

开始前临时记下：当前使用哪台设备、系统版本、目标 Mac 的短账号名、当前网络地址。密码、私钥口令和私钥内容不用写进学习记录。后文的示例地址应替换为你查到的实际地址。

## 先约定怎么读命令

- 标有“Mac 本机终端”的命令在发起连接的 Mac 执行；标有“登录后”的命令在目标电脑执行。
- `alice`、`192.168.1.50` 是虚构示例，使用时替换成你的账号和地址。
- 第五篇的 A/B/C、`buser`/`cuser` 及两个网段同样是教学示例，不能据此推断你的真实网络或设备系统。
- `127.0.0.1` 始终指执行相关操作的设备自己，不能直接拿它从 Windows 连接另一台 Mac。
- 代码块如果写的是“格式说明”或配置文件内容，就不是可以原样在终端执行的命令。
- 教程中的预期结果用于帮助判断；版本号、账号、主机名和提示符可能与你的设备不同。

## 你可以记录的学习进度

以下由你实际完成后勾选，写好文档不代表已经完成设备实验。

- [ ] 能解释 SSH 的用途，知道登录后命令在哪执行。
- [ ] 能根据桌面操作、文件传输、远程开发和自动化任务，判断何时使用 SSH。
- [ ] 在家里 Mac 完成 SSH 自连接、核对指纹并退出。
- [ ] 从家庭网络的 Windows 成功登录 Mac。
- [ ] 用独立学习密钥完成公钥认证，确认没有回退到账号密码。
- [ ] 能通过别名连接，并完成一次上传与下载。
- [ ] 能解释为什么家里的局域网 IP 通常不能直接从公司访问。
- [ ] 能区分“两侧分别登录双网卡 B”“A 经 B 登录 C”和“A、C 直接跨网段通信”。
- [ ] 遇到报错，能先分清网络、主机身份和用户认证阶段。
