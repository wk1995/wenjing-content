# keep-up-with-ai 项目

## 项目简介

- 项目 slug：2026-10-keep-up-with-ai
- 创建日期：2026-10-11
- 项目状态：planning
- 核心主题：普通研发如何跟上 AI 资讯，从"看领导发消息一脸懵"到能跟、能懂、能输出
