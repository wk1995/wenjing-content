# wenjing-content

这个仓库用于沉淀内容生产素材、写作流程和可复用模板，主要服务多平台内容创作：

- 微信公众号技术文：面向普通读者或开发者，完成选题、资料整理、文章大纲、正文、标题和排版建议。
- 抖音视频文案：面向短视频种草、技术科普、产品介绍或投放素材，完成钩子、脚本、分镜和审校。
- 小红书图文：面向种草、产品推荐和品牌内容，完成标题、正文、卖点表达和平台语感优化。

## 目录

- `docs/workflows/`：稳定的内容生产流程。
- `docs/skills/`：从具体选题中提炼出的主题方法论、选题库和写作规范。
- `templates/briefs/`：每次启动写作任务时可复用的 brief 模板。

## 使用方式

1. 先在 `templates/briefs/` 里复制一个最接近的 brief。
2. 填写目标读者、平台、主题、资料来源、输出形式和限制条件。
3. 按 `docs/workflows/` 中对应流程完成资料核验、创作和审校。
4. 将可复用的选题框架、案例和表达方式沉淀到 `docs/skills/`。

## 内容原则

- 不把公众号文章写成教材章节，单篇要独立完整。
- 技术文要用生活场景或真实问题开头，再引出概念和实践。
- 需要最新信息时优先查官方文档、项目仓库、发布公告和一手资料。
- 短视频脚本优先关注前 3 秒钩子、视觉信息密度、口语化和平台合规。
- 所有实践内容默认考虑低配置设备，不把高端硬件当作基础门槛。
